# E-commerce Analytics Dashboard

A customer analysis project using **Python, PostgreSQL, and Power BI**.

## Project Overview
This project analyses customer details, spending behaviour, preferred categories, customer segments, and country-wise revenue.

## Tools Used
- Python (Pandas, NumPy) — data cleaning and preparation
- PostgreSQL — SQL analysis
- Power BI — interactive dashboard

## Project Structure
```text
ecommerce-market-analysis/
├── README.md

├── SQL/ecommerce_analysis.sql
├── PowerBI/ecommerce_dashboard.pbix
├── Reports/project_report.pdf
└── Images/dashboard_screenshot.png
```
*Add only files you have. The raw CSV dataset is not included.*

## Key Results
- 950 customer records analysed
- Total spending: **$97,933.17**
- Average spending per customer: **$103.09**
- 692 customers (72.8%) have zero recorded spending
- Regular and Premium customers contribute about 88% of spending

## Dashboard
Includes customer and revenue KPIs, country analysis, gender distribution, customer spending, preferred categories, and filters for year, segment, and country.
